# Thirupathi Gorige — Personal Portfolio

A responsive portfolio made with plain HTML, CSS, and JavaScript. Includes the supplied profile photo, professional experience, a unique engineering-principles section, and a contact form.

## Run locally
Open `index.html` in a browser. No build tools needed.

## Contact form behavior
The form validates the visitor’s name, email, topic, and message, then opens the visitor’s default email application with a prepared email addressed to `gthiru317@gmail.com`. **This is not an automatic web submission**. Visitors must send the email in their email application. For server-side delivery, connect a trusted form provider or backend and configure spam protection before publishing.

## Publish on GitHub Pages
1. Create a public repository named `YOUR_USERNAME.github.io` (or any repository name).
2. Upload the **contents** of this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, `main`, `/(root)`.
4. Visit `https://YOUR_USERNAME.github.io/` (or `https://YOUR_USERNAME.github.io/REPOSITORY_NAME/`).

## Customize
Edit `index.html` for text, `styles.css` for visuals, and `script.js` for interactions. `assets/profile.jpg` is the provided photograph. `assets/Thirupathi_G_Resume.docx` is the supplied resume. Work examples are experience highlights, not public project repositories. Review all public-facing details before publishing.
